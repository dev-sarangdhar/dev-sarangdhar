## Featured Projects

### [PromptLens](https://prompt-lens-topaz.vercel.app/) — Prompt Analysis & Optimization

Analyzes prompts for clarity, redundancy and token efficiency, then rewrites them while preserving the original intent.

- Clarity analysis that flags vague instructions, ambiguity and missing context
- Token-efficiency checks and intent-preserving rewrites
- Cost comparison across AI providers
- Analysis history, report export, shareable links, team review comments and QR sharing

**Stack:** JavaScript, HTML, CSS, Groq API, Vercel · [Live demo](https://prompt-lens-topaz.vercel.app/)

### [AgentForge](https://agentforgeee.vercel.app/) — AI Agent Prompt Workbench

A full-stack workbench built around one loop: **create, test, evaluate, improve.**

- Build focused, domain-specific agents and run them against real tasks
- Score responses and apply targeted prompt improvements from the feedback
- Firebase authentication and persistent storage for saved agents

**Stack:** Next.js, React, TypeScript, Tailwind CSS, Firebase, OpenAI API · [Live demo](https://agentforgeee.vercel.app/)
