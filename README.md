# ⭐ Featured Projects

## 🧠 PromptLens

### AI Prompt Analysis & Optimization Tool

<div align="center">

<a href="https://prompt-lens-topaz.vercel.app/">
<img src="https://img.shields.io/badge/🚀_Live_Demo-7AA2F7?style=for-the-badge"/>
</a>

</div>

<br/>

**PromptLens** is an AI-powered tool designed to help users write **clearer, leaner and more efficient prompts**.

It analyzes prompts for clarity, redundancy and token efficiency, then generates an optimized version while preserving the original intent.

### ✨ Features

* 🔍 **Clarity Analysis** — Detect vague instructions, ambiguity and missing context
* ⚡ **Token Efficiency** — Identify filler words, redundant phrases and unnecessary explanations
* 🧠 **Smart Rewriting** — Generate optimized prompts while preserving intent
* 📊 **Performance Metrics** — Analyze prompt quality in real time
* 💰 **ROI Calculator** — Compare potential savings across AI providers
* ↩️ **Analysis History** — Save and revisit previous analyses
* 📤 **Export & Sharing** — Export reports and create shareable links
* 👥 **Team Collaboration** — Request reviews and add comments
* 📱 **QR Sharing** — Share optimized prompts through QR codes

### 🧰 Tech Stack

`JavaScript` `HTML` `CSS` `Groq API` `Vercel`

<br/>

<div align="center">

**Write sharper prompts. Spend fewer tokens.**

</div>

## 🤖 AgentForge

### AI Agent Prompt Workbench

<div align="center">

<a href="https://agentforgeee.vercel.app/">
<img src="https://img.shields.io/badge/🚀_Live_Demo-7AA2F7?style=for-the-badge"/>
</a>

</div>

<br/>

**AgentForge** is a full-stack AI-agent workbench designed around a simple workflow:

**Create → Test → Evaluate → Improve**

Users can create domain-specific AI agents, run real tasks, evaluate responses, and use measurable feedback to improve their prompts.

### ✨ Features

* 🛠️ **Agent Builder** — Create focused domain-specific AI agents
* 🧪 **Real Task Testing** — Test agents using practical requests
* 📊 **Response Evaluation** — Analyze generated responses
* 🎯 **Measurable Scoring** — Evaluate agent performance
* 🔄 **Prompt Improvement** — Apply targeted improvements based on feedback
* 🔐 **Authentication** — Firebase-powered authentication
* ☁️ **Saved Agents** — Persist and manage created agents

### 🧰 Tech Stack

`Next.js` `React` `TypeScript` `Tailwind CSS` `Firebase` `OpenAI API`

<br/>

**Build agents. Test them. Prove they work.**
